# 输入先行的场景教学引擎

当前产品基准见 REQUIREMENTS 的“输入先行教学引擎重构”。生活环境承载词汇、短语与表达输入；默认流程是观察 → 学词 → 选择理解 → 听力匹配 → 情境填空 → 跟读与简单回应 → 反馈复习。复杂自由回答是显式高级模式。

## 数据与播放器

`src/journey-schema.ts` 定义 LearningJourney / JourneyStage。`src/life-content.ts` 是七个原创生活过程，每个五阶段、30个词语和10句表达：通勤、超市、餐厅、机场、酒店、看病、办公室。一个阶段包含六个词语（中文、英文含义、例句与译文、搭配）和两句表达（原句、译文、用法分析），以及角色输入、听力题、受控填空和简单回应。

新增过程只添加数据，不开发独立页面。所有选项有明确意义与参考答案；干扰项不能靠语法错误或固定按钮位置暴露答案。填空可配置审核过的等价词；简单输出可配置完整同义回应。医疗、保险、法律与产品事实只训练沟通，不能编造判断、规则或效果。

`JourneyPlayer` 使用共享环境与教学步骤；词语标签支持键盘、释义、发音、例句和词库。`journey-adapters.ts` 将旧11个成人场景、基础场景与课程转换为输入先行训练，保留原听力、情境、表达和事实限制。成人表达族的完整分析在同页展开；原四轮自由沟通与基础专项对话需主动选择。系统课程仍检查原先修关系；自由场景不能解锁必修。

## 记录与复习

`journey-learning.ts` 保存每个阶段的步骤、已发现/辨认词语、听力/填空/跟读/回应证据、调整次数、词汇/听力/回应三个分类的首次表现与完成状态。纠正后不擦除首次错误，不用总错误次数推算虚假的首次分数。必须完成练习才能授予阶段完成；后阶段有先修。刷新回首页后点击今日学习恢复最近未完成过程与步骤。10/20/30分钟建议1/2/3小段，不承诺固定完成速度。

旧v1学习记录和32个核心知识ID保留；新增 journeys 与知识证据字段为可选。备份只重建已知字段，剥离模型及私人配置。生活过程完成不自动授予系统课程或CEFR等级。跟读勾选是自述尝试，不能作为发音质量；有支架输出记录 guided，不能冒充独立输出。

`recordKnowledge` 的 discover 只记首次发现日期；save 只收藏。recognize 记受控含义辨认，与自主practice次数分离。首次正确安排1天，到期正确按3/7/14天延长；同日未到期重复不延长。miss 保存首次错误并安排10分钟后，立即改正不能抹去短复习。个人词库同时显示今天新词、已收藏、已辨认与到期数量。WordReview在温故知新中做实际回忆；已理解的历史单元仍可复习。

## 反馈的范围

受控理解/听力题按审核答案检查。已审核的完整同义简单回应通过规范化后比较，不能退回关键词或目标术语通关。未知开放表达不判错、不用长度给语义分；提供已确认语法规则、参考、自评和可选私人模型。`I joined a meeting yesterday`可以理解；attend概述出席，join也适合加入在线或进行中的会议，不一律纠错。

默认选择方式让用户无需自由组织复杂句子就能学习。文字/麦克风为可选练习，未知说法可回到有支架的选择；麦克风不支持或拒绝时不阻塞学习。

## 图片、语音与安全

`public/visuals/life-atlas.png`是一张原创AI生成的九环境照片风格图集（家、车站、超市、餐厅、机场、酒店、诊室、办公室、车厢），所有阶段复用。约2.6MB，随Pages通过同源CDN缓存；没有大量图片或未经授权的影视人物。共享图片懒加载，失败仍有文字标签与完整教学；有暂停、减少动画支持。照片轻动效不是人物视频、嘴形同步或3D。

自动语音跟随阶段与操作，用户可关闭、重播、0.7倍播放与查看中文。设备TTS有句子边界；备用合成MP3按整句显示，非真人录音。新词没有可靠音标时只提供声音，不捏造IPA。生成器只在开发机使用经过Debian签名索引/SHA256核验的eSpeak NG与FFmpeg；运行网站不需要这些工具。

模型安全机制不变：默认无需AI，无真实Key、Token或个人配置进入仓库和学习备份。模型只在用户明确操作或显式启用的高级模式请求；本阶段没有调用私人付费服务。来源与边界见 docs/RESEARCH.md 与 docs/AI.md。

## 验收入口

`src/journey.test.ts`校验完整数据、原场景适配、词义冲突、证据与先修、透明复习及所有固定语音。`tests/journeys.e2e.ts`实际完成七个五阶段过程，检查首次打开→恢复→下一段、短复习、简单等价回应、未知说法反馈、自动语音和三端截图。旧课程/高级模式测试继续运行。最终结果、截图与真实公开HTTPS记录同步 docs/TESTING.md / HANDOFF.md。
